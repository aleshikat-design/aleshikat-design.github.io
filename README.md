# Портфолио графического дизайнера — Екатерина (@aleshikat)

Эстетичный сайт-портфолио в современном editorial / blush chic стиле для графического дизайнера Екатерины.

## ✨ Особенности проекта
- **Стиль и эстетика**: Нежная пудровая палитра (*Blush Chic*) с возможностью переключения на темный глянец (*Editorial Noir Glam*).
- **Главный экран**: Арочный editorial-фрейм с фотографией Екатерины, бейджами и призывом к действию.
- **Мои направления**: 5 ключевых услуг в формате интерактивной Bento-сетки с тегами и описаниями.
- **Избранные работы**: Интерактивная галерея из 35 реальных проектов с фильтрами по категориям (Соцсети, Маркетплейсы, Презентации, Постеры, Веб-дизайн, Кейсы).
- **Полноэкранный просмотр (Lightbox)**: Модальное окно в высоком разрешении со слайдером, описанием и персональной кнопкой заказа в Telegram.
- **Связь и контакты**: Прямые ссылки на Telegram (`@aleshikat`) и ВКонтакте (`vk.ru/aleshikat`), интерактивный генератор быстрой заявки.
- **Адаптивность**: 100% отзывчивый интерфейс для любых экранов (смартфоны, планшеты, десктопы).

## 🛠 Технологии
- HTML5 (семантическая разметка)
- CSS3 (CSS Variables, Flexbox, Bento Grid, Keyframe анимации)
- Vanilla JavaScript (фильтрация, Lightbox, темы оформления, быстрая заявка)
- Google Fonts (*Cormorant Garamond*, *Plus Jakarta Sans*, *Playfair Display*)
